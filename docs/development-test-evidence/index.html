현재 구현에서 발전시킬 4개 후보 원고 방향

01 · 캠퍼스 디지털 트윈 상호작용

VWorld의 MODEL_NAME·D4 좌표 대체 선택과 Legacy의 건물·강의실 드릴다운을 서로 다른 프로토타입 경로로 구분해 설명한다.

02 · 미기후 위험도 시뮬레이션

기상 입력에서 지역 온도·풍속·복사·UTCI·WBGT를 계산하고 건물 팝업으로 전달하는 파이프라인을 제시한다.

03 · 캠퍼스 에너지 의사결정 UI

태양 위치, 옥상 조건, 손실률을 이용한 월간 태양광 발전량 계산과 강의실 공실·절감 시나리오를 시각화한다.

04 · 교통·안전 비전 연계

YOLO 교통량 API와 번호판·안전 신고 PoC를 디지털 트윈의 외부 관측 계층으로 묶는 확장 구조를 논의한다.

가장 강한 현재 근거 VWorld 선택·SDK 테스트 16건과 태양광 계산 테스트 5건이 실행 증거로 남아 있어, 구현 중심 학부생 논문에 적합하다.
학회별 투고 게이트 KSII는 실제 브라우저 시나리오, ACK는 종단간 재현, IEIE는 라벨 영상 벤치마크, KISM은 사용성 평가가 있어야 준비도를 주장할 수 있다.
표현 원칙
열환경·재질·복사·절감량은 추정 기반 시뮬레이션이다. 실측 데이터나 검증된 에너지 절감 효과로 표현하지 않는다. 교통 비전은 YOLO 자산과 입력 장치가 별도 준비돼야 한다.
한 편만 먼저 낸다면 “VWorld 기반 캠퍼스 디지털 트윈의 이중 선택 경로와 건물 상세 정보 연계”를 KSII용 1~2쪽 구현 논문으로 정리하는 경로가 가장 짧다.

CISC-W 202610/28–30행사 일정만 공식 확인충청지부와 별개인 대체 후보
ICTC는 학부생 발표가 가능하지만 조사본 기준 저자 등록비가 일반 요율 78만~86만원이고 7월 31일이 마감이라 기본 추천에서 제외했다. KMMS, 한국디지털콘텐츠학회, 방송미디어공학회, KIICE는 관련 전례가 있으나 2026 추계 CFP가 확인되지 않아 확정 후보로 쓰지 않았다.

꼭 알아둘 점

  1. KSII 최신 공식 공지는 발표신청 08.20, 논문 08.27이다. 검색 결과의 08.24·09.07은 오래된 값이다.
  2. ACK는 원 조사본의 “CFP 대기” 판단과 달리 7월 13~14일에 이미 상세 공지를 게시했다. 09.16 제출, 10.15 결과, 10.19 최종본·사전등록 일정이 확인됐다.
  3. KISM의 11월 일정은 원 조사본에는 있으나 현재 공식 게시판에서 전용 추계 공지를 찾지 못했다. 삭제하지 않고 미확인 상태로 표시했다.
  4. 센서학회는 대학생 포스터를 허용하지만 현재 프로젝트의 기상·열환경 값만으로는 센서 연구라 보기 어렵다.
  5. 모든 마감·등록비·회원 조건은 제출 직전 공식 페이지에서 한 번 더 확인한다.
